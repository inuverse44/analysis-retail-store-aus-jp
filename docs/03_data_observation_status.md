# データ観測ステータス：AU店舗位置情報

## 1. 観測データの現状 (2026-03-26)
- **対象:** Coles (Australia)
- **取得手法:** OpenStreetMap (Overpass API) via Kotlin Notebook
- **観測数 ($N_{obs}$):** 685件
- **期待数 ($N_{total}$):** 約860件 (2025 Annual Reportより)
- **捕捉率:** $\approx 80\%$

## 2. 欠損の解釈 (Selection Bias)
期待数との乖離（約175件）については、以下の「観測選択効果」が想定される：
- **閾値以下店舗:** `shop=supermarket` というタグに含まれない小規模フォーマット（Coles Local等）の欠損。
- **情報の不均一性:** OSMの更新密度が低い地域（地方・砂漠部）での捕捉漏れ。
- **物理的解釈:** 高質量（大面積）店舗はほぼ捕捉できており、系の主ポテンシャル $\Phi(x)$ を記述するには十分なサンプルであると見なす。

## 3. 次の観測ターゲット：配送センター (DC)
SKU変化率 $R$ と配送距離 $L$ の相関 $R(L)$ を検証するためには、店舗 $x_i$ だけでなく、供給源（DC）の座標 $y_j$ が不可欠である。
- **AUのDC位置:** Colesの主要な物流拠点（メルボルン、シドニー、ブリスベン等）の座標を特定する。
- **距離計量の定義:** 測地線距離（ハバースサイン公式）を用いて $L_{ij} = \text{dist}(x_i, y_j)$ を算出する。

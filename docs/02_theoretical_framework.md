# 理論フレームワーク：重力モデルと摩擦項

## 1. ハフモデル（商圏重力モデル）の物理的定式化
ハフモデル（Huff Model）は、消費者が店舗 $j$ を選択する確率 $P_{ij}$ を以下の形式で記述する：

$$P_{ij} = \frac{S_j / D_{ij}^\lambda}{\sum_k S_k / D_{ik}^\lambda}$$

ここで：
- $S_j$: 店舗の魅力（面積、品揃え等） $\approx$ 「質量 $M$」
- $D_{ij}$: 距離 $\approx$ 「半径 $r$」
- $\lambda$: 距離減衰係数 $\approx$ 「重力指数の補正」

### 宇宙論的アナロジー
店舗を「重力源（ハロー）」、消費者を「テスト粒子」と見なす。
- **AU:** 巨大な質量を持つ孤立した重力源。ポテンシャルの谷が深く、重なりが少ない（$P_{ij} \approx 1$ の領域が広い）。
- **JP:** 多数の小さな重力源が密集。ポテンシャルが複雑に重なり合い、粒子は複数の谷の間を容易に移動できる。

## 2. 気候（Friction Term）の導入
気候を、物流および消費行動に対する「摩擦項（Friction Term）」または「粘性（Viscosity）」としてモデルに組み込む。

### 輸送方程式への寄与
商品の流体的な輸送を考える際、気候 $C$ は以下の摩擦項 $\gamma(C)$ として現れる：

$$\frac{\partial f}{\partial t} + v \cdot \nabla f = - \gamma(C) f$$

- **AUの気候（酷暑・乾燥）:** 
    - 生鮮食品の劣化速度を早める（減衰項の増大）。
    - 配送中の品質維持コスト（コールドチェーン）を増大させ、物流の「実効的な距離」を増大させる。
    - これは「摩擦係数 $\gamma$」の増大に相当し、頻繁な小口配送を抑制する。
- **JPの気候（四季）:**
    - 時間変化する外部ポテンシャル $V_{ext}(t)$ として働く。
    - 季節ごとに「最適SKU」の期待値が振動するため、強制振動系としてSKU変化が誘発される。

## 3. 不変量（Invariant）の探索
土地（面積）や物理的距離という「不変的な計量（Metric）」から、リテールにおける「状態方程式 $P = P(\rho, T)$」のような普遍的な関係式が導き出せないかを探求する。

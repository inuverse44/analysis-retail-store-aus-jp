# 空間統計解析の手法

取得した座標データ（Point Process）に対し、以下の物理学的・数学的解析を適用し、リテール系の「構造」を定量化する。

## 1. 2点相関関数 $\xi(r)$
銀河の分布解析と同様に、店舗間の相関関数を計算する。
$$\text{dP} = n [1 + \xi(r)] \text{dV}$$
- **目的:** 店舗がどの程度のスケールで「クラスター化」しているか、または「排斥（競争による距離確保）」が働いているかを特定する。
- **JPとの比較:** 日本（TRIAL）の $\xi(r)$ と比較することで、市場の「密度ゆらぎ」のパワースペクトルの違いを明らかにする。

## 1.1 Landy-Szalay 推定量の統計的性質

$$\hat{\xi}_{\rm LS}(r) = \frac{DD(r) - 2\,DR(r) + RR(r)}{RR(r)}$$

各ペアカウントの正規化：
$$DD = \frac{n_{DD}}{N_D(N_D-1)/2}, \quad DR = \frac{n_{DR}}{N_D N_R}, \quad RR = \frac{n_{RR}}{N_R(N_R-1)/2}$$

### 非ポアソン点過程への適用

店舗の分布は人口密度ポテンシャルに引かれる非ポアソン点過程であるが、LS推定量は**データが一様ポアソン過程である必要はない**。本質的な要件は「ランダムカタログがデータと同じ選択関数（セレクション関数）をトレースすること」である。

| ランダムカタログ | LS が測るもの |
|---|---|
| 一様ポアソン（バウンディングボックス） | 均質分布からの乖離 = クラスタリング + 人口密度勾配の混合 |
| 人口密度加重（ABS SA2） | 人口密度追随成分を除いた純粋な空間選好 $\xi_{\rm excess}(r)$ |

銀河サーベイでは銀河が大規模構造に従うにもかかわらず LS が使われるのと同じ論理であり、選択関数が既知である限り非ポアソン系に対して LS は成立する。したがって、現在の均質ランダムカタログによる $\hat{\xi}(r)$ には人口密度の非一様性が混入しており、ABS SA2 加重ランダムカタログへの移行が不可欠。

### 不偏性：積分制約（Integral Constraint）

$N_R \to \infty$ の極限での LS 推定量の期待値は：

$$\langle \hat{\xi}_{\rm LS}(r) \rangle = \xi(r) - C_{\rm IC}$$

ここで $C_{\rm IC}$ は積分制約バイアス：

$$C_{\rm IC} = \frac{\iint_V \xi(|\mathbf{x} - \mathbf{y}|)\, W(\mathbf{x}) W(\mathbf{y})\, d^3x\, d^3y}{\iint_V W(\mathbf{x}) W(\mathbf{y})\, d^3x\, d^3y}$$

LS 推定量は内部的に $\int \hat{\xi}(r) W(r) d^3r = 0$ を満たすよう規格化されるため、サーベイサイズを超えるスケールの相関をゼロに押し付ける。この負のバイアスは $L_{\rm survey} \gg r_{\rm corr}$ の極限で消えるが、オーストラリアの場合（$L \sim 3000$ km、相関信号が $r \sim 1000$ km まで有意）では非無視的。大スケールの $\hat{\xi} < 0$（$r > 1000$ km）は真の反相関と IC バイアスの重畳であり、

$$C_{\rm IC} \approx \frac{1}{V_{\rm survey}} \int_0^{L} \xi(r)\, W(r)\, 4\pi r^2\, dr$$

を数値積分で評価して分離する必要がある。

### 分散の過小評価

Poisson 誤差下限 $\sigma_\xi \approx (1+\xi)/\sqrt{n_{RR}}$ は点過程がポアソン的な場合の下限値。クラスター点過程では4点相関関数 $\zeta$ の寄与が加わるため真の分散を過小評価する：

$$\text{Var}[\hat{\xi}(r)] \propto \frac{(1+\xi)^2}{n_{RR}} + O(\zeta)$$

堅牢な信頼区間の推定にはジャックナイフリサンプリング（地理的サブサンプルによる $\hat{\xi}$ の繰り返し計算）が望ましい。

### 空間ジャックナイフ推定量（Delete-$k$-out）

調査領域を $K$ 個の空間パッチに分割し、パッチ $k$ を除いた $N - n_k$ 点で LS 推定量 $\hat{\xi}_k(r)$ を計算する：

$$\sigma_{\rm JK}^2(r) = \frac{K-1}{K} \sum_{k=1}^{K} \left[ \hat{\xi}_k(r) - \bar{\xi}_{\rm JK}(r) \right]^2, \quad \bar{\xi}_{\rm JK}(r) = \frac{1}{K} \sum_k \hat{\xi}_k(r)$$

**実装**（`coles_correlation.ipynb` Cell 41–46）：$K = 8$ 経度スライス（113–154° を等分割、$\Delta\mathrm{lon} \approx 5.1°$/パッチ）を採用。各パッチ除外後に DD, DR, RR を再計算（データ点・ランダムカタログともに除外）。

**スケール依存性の予測**：

| スケール | $\sigma_{\rm JK}/\sigma_{\rm Poisson}$ の予測 | 物理的起源 |
|---|---|---|
| $r < 30$ km | $\approx 1$ | ショットノイズ支配——ジャックナイフとポアソンが一致 |
| $30 < r < 200$ km | $1$–$5$ | 都市内クラスタリングの宇宙分散 |
| $r \approx 666$ km（BAO 主ピーク） | $\gg 1$ | **Sydney–Melbourne ペア**が 1–2 パッチに集中 → パッチ除外で $\hat{\xi}$ が大きく変動 |
| $r > 1000$ km | $\sim 2$–$10$ | 積分制約 + 大スケール構造の宇宙分散 |

Retail BAO ピークでは、$\sigma_{\rm JK} \gg \sigma_{\rm Poisson}$ となり Poisson $S/N \sim 27\sigma$ が大幅に下方修正される。これは「信号が消える」ことではなく、1サーベイからは宇宙分散を平均化できないことを反映する（銀河サーベイの BAO 解析でも同様）。

## 2. ボロノイ分割 (Voronoi Tessellation)
各店舗を核（サイト）として平面を分割する。
- **有効体積 $V_{eff}$:** 各店舗のボロノイ細胞の面積。これはその店舗が独占する「相空間の広さ」に対応する。
- **SKU数との相関:** 仮説「$V_{eff}$ が大きいほど、共存できるSKU数 $N_{sku}$ が多い」を $N_{sku} \propto V_{eff}^\alpha$ の形式で検証する。

## 3. ポテンシャル場 $\Phi(x)$ と勾配 $\nabla \Phi$
ハフモデルを拡張し、任意の地点 $x$ における「店舗の魅力ポテンシャル」を定義する。
$$\Phi(x) = \sum_i \frac{M_i}{|x - x_i|^\lambda}$$
- **消費者のドリフト:** 消費者の行動をポテンシャルの勾配 $\nabla \Phi$ に沿った流体運動として記述する。
- **AU vs JP:** AUは少数の深いポテンシャルの穴（孤立系）であり、JPは浅い穴が複雑に干渉し合う「マルチポテンシャル系」であることを視覚化する。

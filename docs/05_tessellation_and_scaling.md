# テッセレーションとスケーリング則

ボロノイ分割によって現れるパターンの統計的性質から、市場の「秩序度」と「成長ダイナミクス」を解析する。

## 1. 自然界とのアナロジー：成長と衝突
メロンの模様、ひび割れ、細胞組織など、自然界のボロノイパターンは、以下のプロセスで形成される：
1. **核形成 (Nucleation):** 離散的な地点で成長が始まる。
2. **等速成長 (Isotropic Growth):** 各核から周囲へ等速で領域が広がる。
3. **衝突 (Collision):** 隣接する領域がぶつかった地点が「境界（ひび）」となる。

リテール市場において、店舗（核）が商圏（細胞）を広げ、隣接店と顧客を奪い合うプロセスは、まさにこの成長モデルそのものである。

## 2. 面積分布関数 (Area Distribution)
ポアソンボロノイ細胞（ランダムな点配置）の面積 $V$ は、一般に以下のガンマ分布に近い形をとる：
$$P(V) \propto V^{k-1} \exp(-kV)$$
ここで、パラメータ $k$ は系の秩序を表すインデックスとして機能する。

### リテールへの適用
- **AU (Coles/Woolworths):** 
    - 秩序度が極めて高い（$k$ が大きい）と推測される。
    - 物理的・人口的制約に基づき、各店舗が最適化された「結晶格子」に近い配置をとるため、面積分布の分散は小さい。
- **JP (TRIALおよび競合他社):**
    - 秩序度が低い（$k$ が小さい）、あるいは複数の系が重なり合った「多相系」として現れる。
    - 自由競争による「ひび割れ」の結果、べき乗則に近い裾野を持つ可能性がある。

## 3. 破壊力学的な視点：応力解放としての出店
新店舗の出店を、市場の「需要ストレス（応力）」が高まった地点での「ひび割れ（破壊）」と見なす。
- **AU:** ストレスが広域に溜まってから、巨大なひび（大型店）が入る。
- **JP:** 微細なストレスに対して、次々と小さなひび（コンビニ、中規模店）が入る。

この「ひびの入り方（スケール感）」の違いが、最終的なSKUの多様性や変化率にどうフィードバックされているかを考察する。

# SKU動態に関する仮説

## 1. SKU数（分布の広がり）
### 仮説
オーストラリアの1カテゴリあたりの商品数（SKU数）は、日本よりも多い。

### 物理的解釈（相空間の体積）
- **AU:** 1店舗あたりの売り場面積（物理的スペース）が広大である。これは宇宙論で言えば、粒子の収容可能な「相空間の体積 $V$」が大きいことに相当する。選択圧が弱いため、多様な種（SKU）が共存できる。
- **JP:** 都市部を中心とした高密度店舗。限られた $V$ の中で「単位面積あたりの収益（エネルギー密度）」を最大化する必要があり、強い選択圧（フィルタリング）によってSKUが絞り込まれる。

## 2. SKU変化率（時間発展のタイムスケール）
### 仮説
オーストラリアのSKU変化率（月間の入れ替わり）は、日本より小さい（定常的である）。

### 物理的解釈（平均自由行程と粘性）
- 商品の入れ替えを「情報の書き換え」と見なすと、物流コスト $L$（配送距離）が情報の伝播に対する「粘性 $\eta$」として働く。
- **AU:** $L$ が極めて長いため、系の書き換えコストが高く、平衡状態（定常状態）を維持しようとする慣性が働く。
- **JP:** $L$ が短く、平均自由行程 $\lambda$ が小さいため、外部ポテンシャル（季節やトレンド）に対する系の反応速度 $v$ が速い。
